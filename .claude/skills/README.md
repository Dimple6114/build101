# Skills

Project skills for Claude Code (and other agents that read `.claude/skills/`). Each folder holds a `SKILL.md` plus any supporting files. Invoke one with `/<name>`, or let the agent load it when the description matches.

| Skill | What it does | When to use | Source |
|---|---|---|---|
| [grill-with-docs](grill-with-docs/SKILL.md) | Interviews you in rounds until a plan is fully understood, writing glossary terms and ADRs as answers settle | Sharpening the idea, a feature, or an architecture choice before building (user-invoked only) | [mattpocock/skills `grill-with-docs`](https://github.com/mattpocock/skills/tree/49dd158d1076134a641b33efb035946536778336/skills/engineering/grill-with-docs) + [`grilling`](https://github.com/mattpocock/skills/tree/49dd158d1076134a641b33efb035946536778336/skills/productivity/grilling), MIT © 2026 Matt Pocock. Adapted for build101: inlined the `grilling` skill so it is self-contained; reads `docs/` first; writes to `docs/glossary.md` and `docs/decisions/` |
| [domain-modeling](domain-modeling/SKILL.md) | Challenges and sharpens domain terms; maintains the glossary and ADRs | Discussing terminology, editing `docs/glossary.md`, or recording a decision | [mattpocock/skills `domain-modeling`](https://github.com/mattpocock/skills/tree/49dd158d1076134a641b33efb035946536778336/skills/engineering/domain-modeling), MIT © 2026 Matt Pocock. Adapted for build101: `GLOSSARY.md` → `docs/glossary.md` (single context, multi-context map removed); `docs/adr/` → `docs/decisions/`; ADR format reconciled with `docs/decisions/README.md` (one template); build101 examples |
| [ticket-refinement](ticket-refinement/SKILL.md) | Turns a story, idea or existing issue into a structured issue body (context, deliverables, acceptance criteria, open questions) | Writing or breaking down work items; creates/updates GitHub issues in `guidodinello/build101` via `gh` after approval | [claude-dotfiles `ticket-refinement`](https://github.com/guidodinello/claude-dotfiles/tree/main/.claude/skills/ticket-refinement), MIT © 2026 guidodinello. Adapted for build101: targets GitHub issues via `gh` instead of a task manager; reads `docs/` and uses glossary terms; only applies existing labels |
| [code-review](code-review/SKILL.md) | Multi-agent PR review with confidence scoring; posts blocking and non-blocking findings as inline review comments | Reviewing a PR | [claude-dotfiles `code-review`](https://github.com/guidodinello/claude-dotfiles/tree/main/.claude/skills/code-review), MIT © 2026 guidodinello. Adapted for build101: compliance checks cover any CLAUDE.md/AGENTS.md plus accepted ADRs; label swap made optional; generic examples |
| [address-pr-comments](address-pr-comments/SKILL.md) | Fetches unresolved review threads and summaries, triages (fix / decline / clarify), fixes, pushes, and replies to each | A PR has review feedback to work through | [claude-dotfiles `address-pr-comments`](https://github.com/guidodinello/claude-dotfiles/tree/main/.claude/skills/address-pr-comments), MIT © 2026 guidodinello. Adapted for build101: label swap only if the repo has review-state labels; checks against `docs/decisions/`; removed references to skills not in this repo |
| [configure-dependency](configure-dependency/SKILL.md) | Reads official docs before adding a dependency, configures it, and records significant choices as ADRs | Adding a package, framework, hosted service, LLM provider or channel to `backend/` or `frontend/` | [claude-dotfiles `configure-dependency`](https://github.com/guidodinello/claude-dotfiles/tree/main/.claude/skills/configure-dependency), MIT © 2026 guidodinello. Adapted for build101: stack-agnostic (detects the layer's manifest, treats a TBD stack as an ADR); writes ADRs to `docs/decisions/` and research to `docs/research/` |
| [docs-index](docs-index/SKILL.md) | Defines where docs go and keeps every `docs/` folder indexed by a `README.md` | Adding or finding anything under `docs/` | [claude-dotfiles `dev-docs-index`](https://github.com/guidodinello/claude-dotfiles/tree/main/.claude/skills/dev-docs-index), MIT © 2026 guidodinello. Adapted for build101: renamed; the shared, committed `docs/` tree replaces a private notes folder; adds a "where things go" map (research, decisions, glossary) |
