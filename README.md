# build101

An AI community manager for small businesses: the owner sends photos on WhatsApp, a team of AI agents runs their Instagram.

> Status: **idea refinement**. Nothing is decided yet — start in [`docs/`](docs/).

## Repository layout

| Path | What lives there |
|---|---|
| [`docs/`](docs/) | The business side: problem, users, competitors, open questions, decisions |
| [`backend/`](backend/) | Agent, integrations and APIs (stack TBD) |
| [`frontend/`](frontend/) | Owner-facing UI / demo surface (stack TBD) |
| [`.github/`](.github/) | Issue and PR templates, CI later |

## How we work (for now)

- Discuss ideas in issues (use the **Idea / question** template) or PRs against `docs/`.
- When something gets decided, record it in [`docs/decisions/`](docs/decisions/).
- Code comes after the idea is sharp enough to demo.
